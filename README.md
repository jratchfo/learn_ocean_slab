# learn_ocean_slab

Learning Oceanography with a minimal Python project layout.

## Requirements

- Python 3.14+
- [uv](https://docs.astral.sh/uv/)

## Setup (uv)

```bash
uv sync --extra dev
```

## Run tests

```bash
uv run pytest
```

## Example config

Project configuration lives in YAML files, for example `config/settings.yaml`.
